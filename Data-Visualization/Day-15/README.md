The dataset contains monthly sales information of different products such as:

- Face Cream
- Face Wash
- Toothpaste
- Bathing Soap
- Shampoo
- Moisturizer
- Total Profit

## Exercises Practiced

### Exercise 1 - Total Profit Line Plot
- Read the total profit of all months.
- Display the total profit using a line plot.
- Add X-axis and Y-axis labels.
- Add title and month numbers.

### Exercise 2 - Customized Line Plot
- Display total profit using a customized line plot.
- Use dotted line style.
- Use red line color.
- Use circle markers.
- Set marker face color.
- Set linewidth.
- Add legend, title and axis labels.

### Exercise 3 - Multiple Product Sales
- Display sales of all products using a multiline plot.
- Create separate lines for each product.
- Add markers, labels and legend.

### Exercise 4 - Toothpaste Sales Scatter Plot
- Display toothpaste sales using a scatter plot.
- Add month numbers on X-axis.
- Add grid lines.
- Customize the grid using dashed line style.

### Exercise 5 - Face Cream and Face Wash Bar Chart
- Compare Face Cream and Face Wash sales.
- Use grouped bar chart.
- Display both products in the same chart.
- Add labels, title, legend and grid.

### Exercise 6 - Bathing Soap Bar Chart
- Display Bathing Soap sales using a bar chart.
- Add title and axis labels.
- Add grid lines.
- Save the chart as an image file.

### Exercise 7 - Total Profit Histogram
- Display monthly total profit using a histogram.
- Use different profit ranges.
- Add X-axis and Y-axis labels.
- Add title and legend.

### Exercise 8 - Product Sales Pie Chart
- Calculate total yearly sales of each product.
- Display product sales using a pie chart.
- Show percentage of total sales.
- Add labels, title and legend.

### Exercise 9 - Subplots
- Display Bathing Soap and Face Wash sales using subplots.
- Create separate plots for both products.
- Add markers, titles and axis labels.

### Exercise 10 - Random Data Scatter Plot
- Generate random X and Y values using NumPy.
- Create a scatter plot.
- Use different colors.
- Use different sizes for the balls/points.
- Display the random data visually.
