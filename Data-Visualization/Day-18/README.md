- Click and drag a slice to create an exploded segment.
- Add percentage labels using the Chart Options pane.
- Customize the chart formatting.
- Save the Excel file as `Exploded Stilton`.

### Example 2 - 3D Column Chart

- Open the chocolate bar worksheet.
- Select the data for the UK and France only.
- Insert a Column Chart.

### Example 3 - Line Chart

- Select all the required data from the Excel worksheet.

- Format the chart to display time across the X-axis.
- Customize the chart according to the required output.

## Exercises Practiced

### Exercise 1 - Column Chart

**Scenario: Satya Chemicals Pvt. Ltd.**

- Analyze quarterly sales of four product categories: A, B, C and D.
- Compare product sales across Delhi, Mumbai, Bangalore and Chennai.
- Create a Column Chart to represent the sales data.
- Compare the performance of different products across cities.
- Customize the chart for management presentations.

### Exercise 2 - Bar Chart

**Scenario: Mobi World Pvt. Ltd.**

- Analyze mobile phone sales across North India, South India, East India and West India.
- Compare sales of Samsung Galaxy, iPhone, OnePlus and Xiaomi Redmi.
- Create a Bar Chart using the regional sales data.
- Customize the chart to compare mobile sales across regions.

### Exercise 3 - Line Chart

**Scenario: T-Shirt Manufacturing Company**

- Analyze monthly profit data for two consecutive years.
- Create a Line Chart to compare last year's and the current year's performance.
- Display months on the X-axis.
- Display profit values in lakhs on the Y-axis.
- Compare monthly profit trends between both years.

### Exercise 4 - Scatter Plot

**Scenario: E-commerce Call Center**

- Analyze the relationship between sales calls made and sales revenue generated.
- Use sales calls as the X-axis variable.
- Use sales revenue as the Y-axis variable.
- Create a Scatter Plot in Excel.
- Visualize the relationship between calls and revenue.
- Use the chart to understand the sales pattern.
