## Dataset Used

**Sample Superstore Dataset**

The Sample Superstore dataset is used to practice data analysis and visualization in Tableau.

### Fields Used

- Category
- Region
- Sales
- Order Date
- Profit
- Product Name
- Customer Name

## Practicals Performed

### Example 1 - Getting Started with Tableau

- Connect Tableau to a data source.
- Open the Sample Superstore dataset.
- Select the Orders sheet.
- Choose Category and Region as dimensions.
- Choose Sales as the measure.
- Drag and drop fields to create a visualization.
- Display sales for different categories and regions.

### Example 2 - Tableau Navigation

- Explore the File Menu.
- Explore the Data Menu.
- Explore the Worksheet Menu.
- Explore the Dashboard Menu.
- Explore the Story Menu.
- Explore the Analysis Menu.
- Understand the functions of different menu commands.

### Example 3 - Tableau Show Me

- Use the Show Me feature to create visualizations.
- Select Order Date and Profit.
- Create a Line Chart.
- Enable mark labels.
- Select Product Name, Customer Name, Sales and Profit.
- Create a Scatter View using the available visualization options.

### Example 5 - Tableau Data Sources

- Connect Tableau to different data sources.
- Understand file-based data sources such as CSV and Excel.
- Explore relational database connections.
- Understand cloud-based data sources.
- Explore connections using ODBC.

### Example 6 - Custom Data Views

- Understand custom data views in Tableau.
- Perform drill-down analysis using dimension hierarchies.
- Drill down from higher-level data to more detailed data.
- Swap dimensions to change the arrangement of a visualization.
- Analyze data at different levels of detail.

### Example 7 - Extracting Data

- Create a data extract using Data → Extract Data.
- Apply filters to extract a subset of data.
- Add new data to an existing extract.
- Use Data → Extract → Append Data from File.
- Check the extraction history using Data → Extract History.
