## Practical's Performed

### Example 1 - Column Chart
- Create a Column Chart using Excel data.
- Select the required data columns.
- Insert the chart using the Insert tab or F11.
- Customize the chart according to the required data.

### Example 2 - Creating and Customizing Charts
- Select the required data.
- Insert a suitable chart.
- Use **Select Data** to add or remove data.
- Use **Switch Row/Column** to change the way data is plotted.
- Use **Change Chart Type** to select different chart types.
- Customize chart title, labels, legend and grid lines.

### Example 3 - Formatting Chart Area
- Right-click on the chart.
- Select **Format Chart Area**.
- Customize the appearance of the chart area.

### Example 4 - Creating Sparklines
- Select the required Excel data range.
- Insert Sparklines from the Insert tab.
- Create Line, Column and Win/Loss Sparklines.
- Define the Location Range and Data Range.
- Customize sparkline colors using the Design tab.
- Mark specific data points.
- Change sparkline colors for better visualization.

## Exercises Practiced

### Exercise 1 - Customer Services Data
- Add new customer service details in rows 9 and 10.
- Use drop-down lists in columns C and E.
- Edit the description in cell D8.
- Change the width of column D.
- Change the date in cell B8.
- Copy and paste the new date into cells B9 and B10.

### Exercise 2 - Statistics of the Richest People
- Calculate wealth per year for each person.
- Divide wealth by age using an Excel formula.
- Copy the formula down for all people.
- Calculate total wealth per year using **SUM**.
- Calculate average wealth per year using **AVERAGE**.

### Exercise 3 - Stacked Pictures in Chart Series
- Create a chart from the chocolate treats dataset.
- Use **Switch Row/Column** to change the chart layout.
- Copy product pictures from the Pics sheet.
- Paste pictures onto the chart series.
- Use **Format Data Series**.
- Change the Fill setting from Stretch to **Stack and Scale**.
- Repeat the process for different chocolate treats.

### Exercise 4 - Pivot Tables
- Create a Pivot Table from the given data.
- Use filters to analyze the data.
- Filter Travel Method as **Plane**.
- Filter Resort Name beginning with the letter **S**.
- Calculate the average holiday prices.
- Use the drill-down feature to confirm the total number of holidays.
