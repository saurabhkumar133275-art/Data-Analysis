## Steps to Create Charts in Excel

1. Select the required data range.
2. Go to the **Insert** tab.
3. Choose the required chart type.
4. Customize the chart with titles, labels and colors.
5. Adjust chart elements for better readability.
6. Save or copy the chart for reports or presentations.

## Scatter Plot

A Scatter Plot is used to show the relationship between two variables.

### Example Data

- X-axis: Advertising Spend
- Y-axis: Sales Revenue

Example values:

- 500 → 2000
- 1000 → 4000
- 1500 → 5500
- 2000 → 7000
- 2500 → 8000

## Types of Scatter Plot

### 1. Scatter Chart
- Displays individual data points.
- Used to show relationships or correlations between two variables.

### 2. Scatter Plot with Smooth Lines
- Connects data points using smooth curved lines.
- Useful for showing non-linear relationships or smooth transitions.

### 3. Scatter Plot with Straight Lines
- Connects data points using straight lines.
- Useful for showing trends or data progression.

## Customizing XY Scatter Plot

### 1. Add Chart Title
- Add a meaningful title to the chart.
- Example: **Advertising Spend vs. Sales Revenue**

### 2. Add Axis Titles
- Horizontal Axis: Advertising Spend (USD)
- Vertical Axis: Sales Revenue (USD)

### 3. Format Data Points
- Change the color of data points.
- Change marker style.
- Adjust marker size.

### 4. Add Data Labels
- Display values next to data points.
- Customize and move labels for better clarity.

### 5. Add Trendline
- Add a trendline to visualize the overall trend.
- Select **Linear** trendline.
- Display the equation on the chart.
- Display the R-squared value.

### 6. Adjust Axis Scale
- Open **Format Axis**.
- Adjust Minimum and Maximum Bounds.
- Focus the chart on a specific range.

## Practical Example - Analyst Performance

- Analyze months of employment and months with above-average performance.
- Use these two numerical variables to create a scatter plot.
- Months of Employment is used as the independent variable.
- Months with Above-Average Performance is used as the dependent variable.
- Select both columns and insert a Scatter Chart.
- Excel uses the first column as the X-axis and the second column as the Y-axis.
- Add suitable chart elements and customize the scatter plot.
